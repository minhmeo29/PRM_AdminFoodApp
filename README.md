# PRM_AdminFoodApp

## Introduction
PRM_AdminFoodApp is an admin food management application designed to work in conjunction with a user ordering app. This application allows administrators to efficiently manage food information, orders, and customer details.

## Features
- **Food Management**: Add, edit, delete, and view food information.
- **Order Management**: Track and manage customer orders placed through the user app.
- **Customer Management**: Store and manage customer information.

## Technologies Used
- **Programming Language**: Java
- **Development Environment**: Android Studio

## Installation
1. Clone the repository to your local machine:
   ```bash
   git clone https://github.com/minhmeo29/PRM_AdminFoodApp.git
   ```
2. Open the project in Android Studio.
3. Run the application on a device or emulator.
